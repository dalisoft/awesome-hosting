# Fast Inference

**Review date:** 2026-09-26. **Observed announcement:** 2026-08-27.

**Product / availability:** Live monthly-access LLM API.

**Published provider URL:** <https://fast.inference.net>.

Sam Hogan introduced Fast Inference on August 27 as an API giving access to fast Kimi K3, GLM and DeepSeek models for $9/month, with coding-harness integrations. A later reply describes one OpenAI-compatible API. The public product URL is fast.inference.net.

The post does not establish unlimited usage, included-token quantities or a permanent per-token price pair. $9/month is an access subscription, not a gpt-oss token price. The first-purchase coupon is temporary and excluded. A standard free plan or signup credit was not verified.

**Repository decision:** Added under API access subscriptions, keeping its monthly access fee separate from reference-model token prices.
